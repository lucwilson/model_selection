ms-specparam
============

This software repository provides code and utilities for model selection spectral parameterization (`ms-specparam`), developed as part of the research work _A Bayesian Model-Selection Approach for Determining the Number of Spectral Peaks in Neural Power Spectra_.

Information
-----------

Resources for running the `ms-specparam` algorithm in either MATLAB and Python, including further details on each version and scripted tutorials, can be found in their respective folders. The algorithm is also included as part of the [Brainstorm](https://neuroimage.usc.edu/brainstorm/Introduction) (Tadel et al., 2011) software distribution.

For code used to simulate spectra and analyze ms-specparam outputs in the study, as well as the exact simulated spectra used in the study, see the folder titled `simulation`.

For code used to analyze Cam-CAN data in the study, as well as metadata (where permissible to share), see the folder titled `empirical`.

Please contact the authors of this repository for any questions and suggestions.
